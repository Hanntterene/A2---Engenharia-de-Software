# Agendamento de Monitorias

> **Trabalho acadêmico** da disciplina de Engenharia de Software (Atividade Avaliativa A2), do curso de Bacharelado em Engenharia da Computação da UTFPR, Campus Apucarana. Este projeto é um protótipo para fins didáticos, não um sistema em produção.

Das histórias de usuário ao código testado: a partir do e-mail da Coordenação, o trabalho especifica 5 histórias de usuário com critérios de aceitação e implementa uma delas (reserva de horários) em Python, verificada com testes automatizados.

## Estrutura

- `codigo/`: código-fonte e testes (unittest)
- PDF com projeto inicial, relatório de execução e documentação técnica (na raiz)

## Como executar

Python 3.X, sem bibliotecas externas. Os testes rodam com:

    python -m unittest discover -s codigo -v
